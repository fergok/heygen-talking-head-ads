# Luxelight 2.0: product summary

From the user's summary, supplied 2026-11-02. This is the source of truth for product facts. If a web page or Parker disagrees, use this file and tell the user.

A slim, rechargeable LED headlamp with a soft band and one COB light strip across the forehead, from temple to temple. 2.0 is a rebrand of the main product. The headline upgrade is the red light mode, and it comes in new colourways.

The offer is the branded carry case that comes with every order.

## What's new in 2.0

| Upgrade | Detail |
|---|---|
| Red light mode | New mode, and the main upgrade. Positioned as the sign of the original, genuine headlamp |
| Colourways | Black (standard), pink, orange, and camo as a Halloween exclusive. Camo is sold out as of 2026-11-02 (user) |

## Core features

| Feature | Spec |
|---|---|
| Beam | 230° wrap-around COB strip, so no tunnel vision |
| Spotlight | Front spotlight for distance, 350 lumens |
| Side light | Separate lens on the left-side module |
| Modes (power button) | 4 modes, in order: full brightness, half brightness, red, side light |
| Wave sensor | Only works once you click it on. When it's on, you swipe a hand past the side of the lamp, by the temple, to switch the light on or off. With it off, walking past things won't switch the light off by accident |
| Battery | 8 hours per charge |
| Charging | USB-C port on the end tip of the button module, with a red charge LED |
| Weight | 60 g |
| Fit | Adjustable elastic band, anti-bounce, fits over hats and hard hats |
| Weather | Water-resistant, never "waterproof" |
| Durability | Shock-resistant, handles dust, rain, sweat and cold |
