# AI voiceover, bottom of funnel

This style's notes, old scripts, reference ads and finished ads live in its style folder, so this skill only sets the order. Read these in full before starting:

1. `~/Video Editing Test/.claude/skills/ve-video-edit-general/references/video-editing-standards.md`, the main rulebook for every video. It wins wherever the older notes differ.
2. The brand's files in `~/Video Editing Test/Brands/<brand>/`. For LuxeLight these are `brand-notes.md`, `product-summary.md` and `footage.md` (clip notes), which link to the master copies in `~/Documents/LuxeLight Claude/`. They hold the product, offer, voiceover settings (ElevenLabs voice and model), footage clip lists and red light rules.
3. `~/Video Editing Test/Styles/AI voiceover BOF/style.md`, then `Old setup/references/bottom-of-funnel.md` in that folder, which records the user's earlier corrections to this style. Watch the reference ads before writing or cutting.

Past ads' hooks, shots and timings are in `Past ad settings/`. The old scripts haven't been run since the move to this project. Never use their caption code: captions, hook and end boxes, and their timing come from `~/Video Editing Test/tools/captions/house_captions.py`, as in every style (rulebook 7.0). Check the rest of their output against the main rulebook, and tell the user anything that had to change. Use the `ve-video-edit-general`, `apply-notes` and `video-qa` skills for the shared steps. Save new rules where the user's notes belong.
