# Benefit Stack

The whole process lives in the style folder, so this skill only sets the order. Read these in full before starting:

1. `~/Video Editing Test/.claude/skills/ve-video-edit-general/references/video-editing-standards.md`, the main rulebook for every video.
2. The brand's files in `~/Video Editing Test/Brands/<brand>/`. For LuxeLight these are `brand-notes.md`, `product-summary.md` and `footage.md` (clip notes), which link to the master copies in `~/Documents/LuxeLight Claude/`. They hold the product, offer, footage rules, persona research and the chip rules.
3. `~/Video Editing Test/Styles/Benefit stack/style.md`, the process from request to delivery, what the user likes and doesn't, and how to run several ads at once. Follow its steps in order.

The template (`benefit_stack.py`), sounds, songs, example ad and helper scripts are in that same folder. The approved first ad is `~/Video Editing Test/Edits/CAMPSTACK`.

Show the user the copy before building any video. Save new rules where the user's notes belong: general ones in the rulebook, this style's in its `style.md`, brand ones in the brand notes.
